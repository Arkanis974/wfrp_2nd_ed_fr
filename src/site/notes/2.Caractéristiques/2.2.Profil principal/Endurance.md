# Endurance (E)
**Source :** Livre de base p.17 / Core Rulebook p.17 *Toughness (T)*
**Profil :** Profil principal

## 📜 Description
Cette caractéristique représente la capacité de votre personnage à supporter les blessures, la maladie et le poison.

La page "[[2.Caractéristiques/2.1.Les caractéristiques\|2.1.Les caractéristiques]]" indique comment sont déterminées chacune des caractéristiques de votre personnage en fonction de sa race.
