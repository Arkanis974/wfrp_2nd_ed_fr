# Points de blessures (B)
**Source :** Livre de base p.18 / Core Rulebook p.18 *Wounds (W)*
**Profil :** Profil secondaire

## 📜 Description
Cette caractéristique représente la vitalité globale de votre personnage. Elle indique la quantité de dégâts qu'il peut subir avant de se retrouver dans un état critique.

La page "[[2.Caractéristiques/2.1.Les caractéristiques\|2.1.Les caractéristiques]]" indique comment sont déterminées chacune des caractéristiques de votre personnage en fonction de sa race.
