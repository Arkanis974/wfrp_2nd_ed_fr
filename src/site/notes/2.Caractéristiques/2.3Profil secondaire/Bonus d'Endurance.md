# Bonus d'Endurance (BE)
**Source :** Livre de base p.18 / Core Rulebook p.18 *Toughness Bonus (TB)*
**Profil :** Profil secondaire

## 📜 Description
Cette caractéristique, dérivée de l'[[2.Caractéristiques/2.2.Profil principal/Endurance\|Endurance]], détermine la résistance aux dégats.

La page "[[2.Caractéristiques/2.1.Les caractéristiques\|2.1.Les caractéristiques]]" indique comment sont déterminées chacune des caractéristiques de votre personnage en fonction de sa race.
