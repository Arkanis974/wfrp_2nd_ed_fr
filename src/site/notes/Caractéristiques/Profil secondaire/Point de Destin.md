# Points de Destin (PD)
**Source :** Livre de base p.18 / Core Rulebook p.18 *Fate Points (FP)*
**Profil :** Profil secondaire

## 📜 Description
Cette caractéristique représente la chance et, dans une certaine mesure, la destinée de votre personnage. Les points de Destin peuvent servir à éviter une mort certaine. Votre MJ vous en dira davantage sur cet aspect du jeu. Les [[Points de Fortune\|Points de Fortune]] qu'un personnage peut dépenser par jour sont égaux à ses Points de Destin.

La page "[[Les caractéristiques]]" indique comment sont déterminées chacune des caractéristiques de votre personnage en fonction de sa race.
