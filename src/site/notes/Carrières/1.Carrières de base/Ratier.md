# Ratier
**Type :** Carrière de base
**Source :** Livre de base p.54 / Core Rulebook p.49 *Ratcatcher*
## 📜 Description
Le Ratier est un personnage bien connu au travers de l’[[Empire\|Empire]] puisqu’on le trouve aussi bien dans les villages que dans les grandes villes. Ce curieux personnage gagne sa vie en éliminant la vermine qui infeste l’ensemble des communautés en cette ère insalubre. Les Ratiers sont généralement des voyageurs, mais les plus grandes villes en abritent de véritables contingents permanents. Les rats constituent bien évidemment leurs ennemis principaux mais ils se chargent également des taupes, des souris et d’animaux tout aussi nuisibles. Les Ratiers citadins passent le plus clair de leur temps dans les égouts, évoluant dans des ruisseaux d’ordures pour traquer leurs proies. Certes, il s’agit d’un travail dégoutant, mais il a le mérite de prévenir les épidémies.
